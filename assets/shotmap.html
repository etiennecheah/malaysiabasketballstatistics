Copy as

In vMix open Settings → Shortcuts → Add, press a key, choose the function BrowserNavigate, pick the shot map input and paste a link as the Value. The graphic switches without reloading. Players are set by team and shirt number, so the same shortcuts work for every game.

Finding the match ID

It is the number in the game's link: on Genius Sports …/u/MABA/2896897/…, on HoopStatsMY …/watch/2896897 or a box score link. Paste the whole link if that is easier.

Live during the game

The map reads the official FIBA LiveStats feed, which carries the spot of every shot. It checks every 10 seconds and new shots fly in. The feed runs about 30 seconds behind the court.

Halftime and timeouts

Game moment freezes the map at the end of a quarter, at halftime or at any timeout, with points and field goals as they stood then.

What is drawn

LiveStats records where a shot was taken, not its flight, so each arc is a drawn curve to the rim.
